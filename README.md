# knn-classifier

Консольное приложение для классификации точек на плоскости методом
k ближайших соседей (лабораторная работа № 1).

Версия: 1.2 (добавлен экспорт выборки в CSV)

## Запуск

    python knn.py
## Экспорт выборки в CSV

После ввода (или загрузки) обучающей выборки программа автоматически
сохраняет её в файл `data.csv` в формате:

    x,y,label
